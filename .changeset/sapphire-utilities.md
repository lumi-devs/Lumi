Replace hand-rolled utilities with `@sapphire/*` npm versions, no backward-compat shims. `parseDuration` is backed by `@sapphire/duration`'s `Duration` (plus `wk`/`wks` tokens and `a minute` phrasing; month is 365/12 days instead of 30). `formatDuration` now delegates to `DurationFormatter`, so output changes contract from single-unit compact (`50s`, `1m`) to multi-unit prose (`50 seconds`, `1 minute 30 seconds`), with no clamping of zero/negatives (`-5 seconds`). `relativeTimestamp`/`shortTimestamp` are deleted — no production callers existed; use `time()` from `@discordjs/formatters` (now a direct dependency) instead. The hand-rolled `Mutex` is gone (`packages/shared/src/mutex.ts` deleted) — all queues use `@sapphire/async-queue`'s `AsyncQueue` directly. `isSnowflakeId` validates through `DiscordSnowflake.deconstruct`. Deferred-delete timers and the addon `util.sleep` host method use `@sapphire/utilities`' `sleep`. `withTimeout` is reworked on `sleep` + `AbortController`: the deadline rejects with `TimeoutError` first and aborts the handed-out signal on the next microtask, so the race deterministically settles with `TimeoutError` while `fn` still sees the abort; no lingering timers, no unhandled rejections. `@lumi/shared` (`primitives.ts`) re-exports `cutText`, `chunk`, `isNullish`, `tryParseJSON`, `deepClone`, `mergeDefault`, `Time` and friends from `@sapphire/utilities` + `@sapphire/time-utilities` — the vendored copies are deleted. `Ms` is gone, use `Time` (identical millisecond values). Accepted npm deltas: `deepClone` now clones TypedArrays instead of throwing, and `mergeDefault`/`tryParseJSON` take the npm type signatures. `canSendMessages` stays hand-rolled: the `discord.js-utilities` counterpart is channel-only (DMs always true, resolves via `channel.client`) and cannot serve the guild-message-scoped `guild.members.me` null-aware shape without loosening the contract.
