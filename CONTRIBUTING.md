# Contributing to Lumi

Thank you for your interest in contributing to Lumi!

## Getting Started

Please see the [README.md](README.md) for instructions on setting up a local development environment.

## Architecture and Guidelines

For a comprehensive overview of how Lumi is structured, the module system, conventions, and things NOT to do, please read [AGENTS.md](AGENTS.md). It serves as our primary architectural document and style guide.

## Pull Requests

1. Fork the repository and create your branch from `main`.
2. Ensure you have run `bun run typecheck` and `bun run lint` to fix any formatting or type issues.
3. Ensure any new features include appropriate tests.
4. Open a pull request with a clear title and description of your changes.
