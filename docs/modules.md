# Bundled Modules

Every module is managed with `/module` (owner-only): `list`, `info`,
`enable`, `disable`, `install`, `uninstall`, `reload`, `load`, `unload`,
`status`, `update`, `pin`, `unpin`, `help`.

| Module | Manage | What it does |
|---|---|---|
| 💤 AFK | `/module info afk` (owner) | Set yourself AFK with automated status and mention alerts. |
| 🛡️ Core | `/module info core` (owner) | Essential bot commands, module management, and administrative panels. |
| 🖥️ Dashboard | `/module info dashboard` (owner) | Web dashboard integration and RPC management endpoints. |
| 🪙 Economy | `/module info economy` (owner) | Guild currency with payday, transfers, slots, and an audit ledger. |
| 🚫 Filter | `/module info filter` (owner) | Automod rule engine with regex patterns, invite blocking, and heat scoring. |
| 📋 Logging | `/module info logging` (owner) | Server event logging for moderation, messages, and member actions. |
| 🏆 Leveling | `/module info leveling` (owner) | Message and voice XP with rank cards and leaderboards. |
| 🛡️ Moderation | `/module info mod` (owner) | Staff moderation tools: warn, mute, kick, ban, and case tracking. |
| 🎭 Reaction Roles | `/module info reactionroles` (owner) | Self-serve role menus via buttons, dropdown, or reactions. |
| 🛡️ Security | `/module info security` (owner) | Server protection: anti-nuke thresholds, raid detection, and verification. |
| 📌 Sticky Messages | `/module info sticky` (owner) | Keep a message pinned to the bottom of a channel. |
| 🔊 Temp Voice Channels | `/module info tempvc` (owner) | On-demand temporary voice channels that clean up when empty. |
| ⚙️ Utility | `/module info utility` (owner) | Helpful server tools, avatar lookups, and user info commands. |
| 👋 Welcome | `/module info welcome` (owner) | Welcome cards, goodbye cards, join roles, and DM greetings. |
