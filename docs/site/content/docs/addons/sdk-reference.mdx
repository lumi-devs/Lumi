The one supported import surface for third-party addon code is the `lumi` package and its
subpath exports (`lumi/commands`, `lumi/config`, `lumi/discord`, `lumi/interactions`, `lumi/kv`,
`lumi/permissions`, `lumi/redis`, `lumi/scheduling`, `lumi/ui`, `lumi/utils`), mapped in the
repo's root `package.json` `"exports"` field to files under
`packages/core/src/lib/addon-sandbox/sdk/`. Addon code should never import `#lib/*` or
`#modules/*` directly — those aliases are for host code, not addons, and are not a stable
surface.

Below is every function, class, interface, type, and constant each subpath exports, grouped by
import path, with the signature exactly as the TypeScript compiler sees it. This page has
<SdkExportCount /> entries and is generated from the SDK source on every docs build — it can
never drift out of date with the actual package.
