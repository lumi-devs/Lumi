---

Every Lumi release is published on the [GitHub Releases](https://github.com/lumi-devs/Lumi/releases)
page, with notes generated from the pull requests merged since the previous release. The whole
monorepo (worker, dashboard, core and the rest) ships as one version, so that page is the complete
history.

For this release's breaking changes specifically, see the [FAQ](/docs/meta/faq) and watch for
version-support notes on [Updating](/docs/getting-started/updating).
