# Lumi Docs

Self-hosted modular Discord bot: one process, one `src/`, modules loaded
in-process with no sandbox.

## Start here

- `install.md` - prerequisites, configure, migrate, run.
- `operators.md` - env, Docker, database, CLI, backups.

## Writing modules

- `guide_module.md` - creating a module: shape, commands, config, framework API.
- `guide_publish.md` - publishing an addon: repos, manifests, signatures.

## Framework reference

- `framework_config.md` - scoped config and config scopes.
- `framework_bank.md` - guild economy.
- `framework_leveling.md` - message and voice XP, formulas, boards.
- `framework_permits.md` - permit nodes and evaluation.
- `framework_commands.md` - commands, cooldowns, follow-up prompts.
- `framework_events.md` - listeners, event bus, utilities.
- `framework_tasks.md` - scheduled tasks and one-shot timers.
- `framework_i18n.md` - translations.
- `framework_modlog.md` - cases, case types, modlog routing.
- `framework_rpc.md` - dashboard RPC bridge.
- `framework_utils.md` - formatting, cards, antispam, filters, purge, tunnel.
- `framework_data.md` - KV store, module files, shared tokens, feature flags.

## Bundled modules

- `modules.md` - what ships and what each module does.
