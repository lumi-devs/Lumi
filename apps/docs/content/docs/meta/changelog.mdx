title: Changelog
description: Where to find what changed between releases.
---

Lumi tracks changes with [Changesets](https://github.com/changesets/changesets) — each package
(`apps/worker`, `apps/dashboard`, `packages/core`, and the rest) has its own `CHANGELOG.md`,
compiled from the individual changeset files under `.changeset/` on release. Rather than
duplicate that here, see:

- The [GitHub Releases](https://github.com/lumi-devs/Lumi/releases) page for release notes.
- Each package's own `CHANGELOG.md` in the repository for granular, per-package history.

For this release's breaking changes specifically, see the [FAQ](/docs/meta/faq) and watch for
version-support notes on [Updating](/docs/getting-started/updating).
