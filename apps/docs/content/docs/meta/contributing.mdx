This site documents running and using Lumi. For contributing to the project itself — code,
translations, or the docs you're reading now — see the repository's own
[CONTRIBUTING.md](https://github.com/lumi-devs/Lumi/blob/main/CONTRIBUTING.md) rather than a
duplicate copy here.

A few pointers specific to this docs site:

- Content lives under `apps/docs/content/docs/**/*.mdx`. The tables inside
  `apps/docs/content/docs/reference/` are generated at build time from source
  (`apps/docs/scripts/generate-content.ts`) — edit the source they're generated from, not the
  rendered page.
- Add-on authoring docs are intentionally thin this release — see
  [Add-ons Overview](/docs/addons/overview).
