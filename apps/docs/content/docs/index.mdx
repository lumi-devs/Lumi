Lumi is a self-hosted, modular Discord bot built on Bun, TypeScript, [Sapphire](https://sapphirejs.dev),
Postgres, and Redis. Feature modules snap in per guild, and a Next.js dashboard administers them
over an internal RPC bridge — no bot token ever leaves the worker.

## Where to start

- **[Getting Started](/docs/getting-started/introduction)** — boot the whole stack with Nix and
  Docker Compose, invite the bot, and run your first commands.
- **[Guides](/docs/guides/dashboard)** — task-oriented walkthroughs for the dashboard and every
  built-in module: moderation, automod, economy, welcome cards, reaction roles, temp voice
  channels, and more.
- **[Reference](/docs/reference/architecture)** — exhaustive, generated-from-source tables: every
  environment variable, command, permit node, and RPC action.
- **[Add-ons](/docs/addons/overview)** — the third-party module story (being revised for 0.4).
- **[Deploy](/docs/deploy/overview)** — Docker Compose and Kubernetes deployment guides.
