`packages/core/src/modules/*/commands/`. The **Permit** column is the permit node a member needs
— see [Permits](/docs/reference/permits) for what each node means and
[Permits guide](/docs/guides/permits) for how to grant one. A command with no permit listed has
no `requiredPermit` set and is gated only by Discord's own default member permissions, if any.
