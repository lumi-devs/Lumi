Lumi is a self-hosted, modular Discord bot. One worker process — sharded with discord.js's
`ShardingManager` — runs every built-in module, and a separate Next.js dashboard administers it
over an internal HTTP RPC bridge. The dashboard never holds the bot token and never opens a
database connection directly.

Twelve built-in modules ship with Lumi: `afk`, `core`, `dashboard`, `economy`, `filter`,
`logging`, `mod`, `reactionroles`, `security`, `tempvc`, `utility`, and `welcome`. `core` and
`dashboard` are infrastructure and can't be disabled; the other ten are ordinary feature modules a
server admin can turn on or off per guild. See the [module reference](/docs/reference/environment-variables)
and [module guides](/docs/guides/dashboard) for what each one does.
